For this design, I will be utilizing a master state counter. This will be divided into 3 sections: State Memory (Sequential), Next-State Logic (Combinational), Master counter and outputs.

State Memory
-Triggered by the posedge of the clock
-Blindly copies the value of next_state to current_state
-When reset is triggered or active low/high (set by the design) set the value of current_state back to `IDLE`

Next State Logic
- Each state will be labeled by either 4 bit binary number such as 4b'0000 - 4'bXXXX or 4'd0. 
	- will be evaluated by each case
		- case(current_state)
- For Compute state, will need to see if the counter is equal to 46 clock cycles then move onto DRAIN. 
	- if it didn't reach 46 assign next_state to COMPUTE as it will still be computing

Master Counter and Outputs
- if current_state doesn't equal next_state = FSM is moving -> force the master counter to 0
	- Should aim to reset the master counter during a state transition to ensure it starts at exactly 0 on the precise clock cycle the FSM enters compute or drain phase. 
- if they match, increment the master counter by 1.
- based on what current_state is drive the global control signals such as valid_in or output_enable
